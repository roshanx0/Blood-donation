# Blood Donation System

Built as a college mini-project @cce 

A full-stack web application for managing blood donation activities, connecting donors, blood banks, organizations, and administrators in one platform.

## Short Description

This project helps users discover nearby blood banks, register for donation camps, track donation history, and request blood when needed. It also provides a dashboard for admins and partner organizations to manage operations efficiently.

## Features

- Donor registration and authentication
- Blood bank and organization management
- Blood camp creation and participation
- Donation history tracking
- Blood request handling
- Admin and analytics dashboards
- AI chatbot support for basic assistance

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

## Project Structure

- backend/: API server, routes, controllers, and models
- frontend/: React app for the user interface

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd blood-donation-system
```

### 2. Backend setup

```bash
cd backend
npm install
cp .env.example .env
npm start
```

### 3. Frontend setup

```bash
cd ../frontend
npm install
cp .env.example .env
npm run dev
```

## Environment Variables

Create local environment files using the provided examples:

- backend/.env.example
- frontend/.env.example
